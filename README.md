# Project: Mini Message Board

A simple message board application built with Node.js, Express, and EJS. This project serves as an implementation of [The Odin Project's Mini Message Board assignment](https://www.theodinproject.com/lessons/node-path-nodejs-mini-message-board), demonstrating server-side rendering, routing, Model-view-controller (MVC) pattern, and reusable templates with EJS.

## Key build dependencies

### Core & Routing

- **Node.js**
- **Express**

### Styling

- **EJS** — used in layouts & reusable templates
- **CSS** — vanilla CSS, scoped using [**Block, Element, Modifier** (BEM) naming methodology](https://bem.info/en/methodology/).

## Getting started

### Prerequisites

Make sure you have npm (^11.x) and Node.js (^24.x) installed on your machine.

### Installation

Clone the repository:

```sh
git clone git@github.com:attritionxd-oss/odin-project-mini_message_board.git
cd odin-project-shopping_cart
```

Install dependencies:

```sh
npm install
```

Start the dev server:

```sh
npm run dev
```
